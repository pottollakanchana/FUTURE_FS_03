# 🍽️ Family Restaurant Website - Local Business Growth Project

This project was built as part of *Task 3* for my web development internship. The goal was to design and develop a professional, mobile-responsive website for a real local business to help them improve their online presence and attract more customers.

Live Deployment URL: [https://bucolic-seahorse-5775cd.netlify.app/]

## 🚀 The Business Problem Solved
Many local family restaurants lose potential customers because their menus are only available as blurry photos on Google Maps or social media, which are frustrating to read on mobile phones. This website fixes that problem by providing a clean, fast-loading, dynamic homepage optimized specifically for smartphones and desktops.

## ✨ Features Included
- *Mobile-First Responsive Layout:* Designed using CSS Media Queries to look perfect on all screens.
- *Clear Call-to-Action (CTA):* A prominent "View Our Menu" button to guide users directly to the food listings.
- *Menu Highlights Section:* Structured grid cards featuring popular dishes, clear pricing, and descriptions.
- *About Section:* A welcoming narrative highlighting the restaurant's family-friendly atmosphere.
- *Essential Business Details:* Easily accessible location details, phone number, and opening hours to maximize foot traffic.

## 🛠️ Technologies Used
- *HTML5:* For clean, semantic website structure.
- *CSS3:* For modern styling, custom layouts (Flexbox and CSS Grid), and full responsiveness.
- *Google Fonts / Unsplash:* For professional typography and high-quality food photography assets.

## 🎯 Value Proposition (The Pitch)
By deploying a website like this, a local restaurant can capture search traffic from customers looking for dining options in their neighborhood. Making the menu easily readable on a phone eliminates friction, builds customer trust, and directly drives more weekend table bookings and takeaway orders.
